# Currency Converter

## Description
A Java console application that converts currencies between INR, USD, and EUR using predefined exchange rates.

## Features
- INR to USD conversion
- INR to EUR conversion
- USD to INR conversion
- EUR to INR conversion
- Menu-driven interface
- User-friendly console interaction

## Technologies Used
- Java
- IntelliJ IDEA
